## 3 ต.ค. 2569

### แก้ Vercel build — `No Output Directory named "dist" found`

**อาการ:** Vercel build สำเร็จแต่ error ตอนจบ
`Error: No Output Directory named "dist" found after the Build completed.`

**สาเหตุ:** VitePress เขียน output ไปที่ `.vitepress/dist` แต่ Vercel รอ `dist` ที่ root

**แก้:** เพิ่มไฟล์ `vercel.json`

```json
{
  "$schema": "https://openapi.vercel.sh/vercel.json",
  "framework": "vitepress",
  "buildCommand": "pnpm run build",
  "outputDirectory": ".vitepress/dist"
}
```

**ผลลัพธ์ที่ตรวจจริง**
- build สะอาดผ่านใน 6.23s → `.vitepress/dist` มี 95 ไฟล์ มี `index.html` + `404.html`
- `vercel.json` parse ผ่าน
- ไม่กระทบ Docker/Coolify เดิม — Dockerfile ยัง copy จาก `/app/.vitepress/dist`
- warning `The language 'conf'/'env' is not loaded` = ปกติ (syntax highlighting) ไม่ทำให้ build พัง

**ยังไม่ทำ:** commit / push — remote คือ GitHub → พี่ฆัง push เอง

### เพิ่มกฎถาวรเรื่องขอบเขตโฟลเดอร์

ผู้ใช้ได้สั่งให้บังคับใช้กฎ **"ห้ามออกนอกโฟลเดอร์โครงการเด็ดขาด"** โดยอ่านหลักการจาก AGENTS.md ทั้งระดับโลก (`~/.config/opencode/AGENTS.md`) และระดับโปรเจกต์ (`AGENTS.md` ในโฟลเดอร์งาน) ดังนี้:

**ขอบเขตที่อนุญาต**
- ทุก session ผูกกับ `business-planning` เท่านั้น
- ห้ามแตะ แก้ อ่านเพื่อทำงาน หรือวิ่งคำสั่งในโฟลเดอร์อื่นนอก `business-planning` เว้นแต่พี่ฆังสั่งชัดเจน
- "ไม่ได้สั่ง" = ห้ามทำ · "น่าจะเกี่ยวข้อง" ไม่ใช่คำสั่ง
- ห้ามออกไปแก้โปรเจกต์อื่นแล้วกลับมาบอกว่าทำเสร็จ — ต้องทำให้เสร็จในโฟลเดอร์งานก่อน
- ถ้าได้ log/error ที่ไม่รู้ที่มา → ตรวจ `pwd` และยืนยันว่าโปรเจกต์ไหนก่อนลงมือ

**ข้อยกเว้นที่อนุญาต**
- ไฟล์กฎส่วนกลางของฌอนเอง (`~/.config/opencode/AGENTS.md`) — เพราะพี่ฆังสั่งให้บันทึกกฎ
- ไฟล์ที่พี่ฆังระบุชัดเจนเป็นลายลักษณ์อักษร
- `AGENTS.md` ของโฟลเดอร์งานเอง

**ข้อห้ามเด็ดขาด**
- ห้ามออกไปโฟลเดอร์อื่น "เพราะคิดว่าเกี่ยวข้อง" แม้จะเป็นโปรเจกต์ของเราเอง
- ห้ามทำงานข้ามโปรเจกต์แล้วมาบอกว่าเสร็จ — งานของโฟลเดอร์ไหน ต้องจบที่โฟลเดอร์นั้น
- ห้ามอ้างว่า session ก่อนหน้าทำไว้ให้แล้ว เพื่อข้ามงานที่ยังไม่เสร็จในโฟลเจกต์ปัจจุบัน
